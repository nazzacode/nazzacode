Hi, I’m @nazzacode.

### Projects

- **Yotland**: a keyboard-driven Linux desktop on Hyprland. Public release in progress.
- **[apgo](https://github.com/nazzacode/apgo)** (arpeggio): a leader key for Hyprland. Tap Super, type a few letters. Emacs which-key for the desktop. Part of Yotland.
- **[Glass Mode](https://github.com/nazzacode/glass-mode)**: websites as frosted, liquid glass over your desktop. Text stays readable. [Site](https://nazzacode.github.io/glass-mode/).
- **[Readwise terminal quotes](https://github.com/nazzacode/readwise_terminal_quotes)**: a random Readwise highlight every time you open a terminal.
- **[Hide Sidebar for WhatsApp Web](https://github.com/nazzacode/whatsapp-web-hide-sidebar)**: browser extension that hides the chat list so the open chat fills the window. Firefox, Zen and Chrome.
